# Tipografia da apresentação clara

Os arquivos `Inter18pt-Regular.ttf` e `Inter18pt-Bold.ttf` são instâncias estáticas da fonte Inter oficial, com tamanho óptico 18 e pesos 400/700, para aproximar o recorte tipográfico `Inter18pt` identificado no PDF de referência. A família da instância foi nomeada `Inter18pt` para corresponder à referência.

Origem: [Google Fonts, Inter](https://github.com/google/fonts/tree/main/ofl/inter). Licença SIL Open Font License em `Inter-OFL.txt`.

As fontes são usadas nos renders e referenciadas pelos objetos de texto editáveis do PowerPoint. Não estão incorporadas no PPTX; instale os TTF no computador que vai editar/apresentar para manter a tipografia. O processo de autoria registra essas fontes no renderizador local, sem instalar fontes globalmente.
